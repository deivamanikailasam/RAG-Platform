## [Unreleased]

### Added

- Step 1: `bootstrap/Brewfile` with the Core CLI tools (git, gh, jq, yq, just, direnv, wget, tree), reference shell snippets for Homebrew's PATH and the direnv hook under `bootstrap/home/`, and the step write-up.
- Step 2: `uv` added to the Brewfile, reference global uv config (`bootstrap/home/.config/uv/uv.toml`: only-managed interpreters, manual downloads, commented company mirror), the `bootstrap/labs/uv-lab.sh` lab replay script, and the step write-up.
- Step 3: OrbStack and dive added to the Brewfile, reference Docker engine config with log rotation (`bootstrap/home/.orbstack/config/docker.json`), `bootstrap/orbstack-setup.sh` (VM cap 24 GB / 8 CPUs), the `bootstrap/labs/container-lab.sh` lab replay script, `bootstrap/NOTES-step3.md` decisions (models native, services in containers), and the step write-up.
- Step 4: monorepo skeleton (`libs/`, `services/`, `infra/`, `evals/`, `tests/`, `scripts/`, `docs/`), hygiene files (`.gitignore`, `.gitattributes`, `.editorconfig`), project README, PR template and CODEOWNERS, the uv workspace (`pyproject.toml`, `.python-version`, `uv.lock`) with the first shared library `libs/rag-common`, the `justfile` command menu, the ADR template with ADR-0001 to ADR-0004 and index, `bootstrap/git-setup.sh` plus reference `~/.gitconfig` / `~/.ssh` copies, and the step write-up.
- Step 5: code quality gates: ruff, mypy, pytest and pre-commit as locked dev dependencies configured in the root `pyproject.toml`, the first `rag-common` unit test, `.pre-commit-config.yaml` (file hygiene, detect-private-key, gitleaks, no-commit-to-branch, ruff, strict mypy, uv.lock check, Conventional Commits message check, pytest at pre-push; generic hooks frozen to SHAs), new `just` recipes with `just check` running every gate, `.vscode/extensions.json`, ADR-0005, and the step write-up.
- Step 6: local secrets handling: `age` and `sops` in the Brewfile, `.sops.yaml` encryption rules, `scripts/new-dev-secrets.sh` (random dev secrets encrypted into `secrets/dev.enc.env`), the `secrets-encrypted` pre-commit hook (`scripts/check-sops-encrypted.sh`) and `.gitleaks.toml`, the file-based container secret demo `infra/compose/secrets-demo.yaml`, `.envrc` (direnv: venv, SOPS key, Keychain HF token), `.env.example`, `secrets-*` / `with-secrets` just recipes, `rag_common.settings` with pydantic-settings and `SecretStr`, the secret-leak runbook, ADR-0006, and the step write-up.
- Step 7: model serving with mlx-lm: the isolated, locked `infra/model-serving` uv project (excluded from the workspace) and its `models.yaml` model inventory, `scripts/install-model-agents.sh` launchd agents for qwen-quality (:8081) and qwen-fast (:8082) with reference plists under `bootstrap/home/Library/LaunchAgents/`, model `just` recipes (`models-download`, `serve-quality`, `serve-fast`, `models-up`, `models-down`, `models-health`, `models-logs`, `bench`), `scripts/bench_models.py` with tests and the `docs/benchmarks/models.md` results table, ADR-0007, new glossary terms, and the step write-up.
- Step 8: embedding and reranker servers with Hugging Face TEI: `text-embeddings-inference` in the Brewfile, the embedder (Qwen3-Embedding-0.6B, :8083) and reranker (bge-reranker-v2-m3, :8084) in `models.yaml` with the embedding contract, `scripts/model-path.sh`, `scripts/run-tei.sh` (localhost, own metrics ports, `TEI_API_KEY` from SOPS by environment), `scripts/install-tei-agents.sh` launchd agents with reference plists, `TEI_API_KEY` in `.env.example` and the secrets generator, new `just` recipes (`serve-embed`, `serve-rerank`, `search-models-up`, `search-models-down`, `health`, …), `scripts/embed_demo.py` and `scripts/bench_embeddings.py` with tests and a results table, ADR-0008, new glossary terms, and the step write-up.
- Step 9: the LiteLLM gateway: `infra/config/litellm/config.yaml` mapping the role names `qwen-quality`, `qwen-fast`, `embedder` and `reranker` to the exact backends, the platform's first Compose stack `infra/compose/compose.yaml` (LiteLLM v1.104.0 pinned by tag@digest, 127.0.0.1:4000 only, read-only config, file-based secrets via a wrapper, healthcheck, restart, `no-new-privileges`, limits), `just up` / `down` / `ps` / `logs` / `gateway-health` / `gateway-smoke`, `scripts/gateway_smoke.py` (OpenAI SDK smoke test with bad-key and unknown-model checks) with tests, `LLM_GATEWAY_URL` / `LLM_GATEWAY_KEY` in `.env.example`, ADR-0009, new glossary terms, and the step write-up.
- Step 10: gateway governance: a private, digest-pinned `litellm-db` Postgres 17 (no published port) with `DATABASE_URL` and `LITELLM_SALT_KEY` from secret files, both new secrets in the generator and `.env.example`, shadow prices for the local models (`docs/finops/shadow-pricing.md`), retries, cooldown and chat-only fallbacks with `store_model_in_db: false`, the access policy `docs/security/gateway-access-policy.md`, `scripts/gateway_admin.py` (teams, virtual keys, info, block) and `scripts/gateway_limits_test.py` (allow-list, rate-limit and budget proof) with `just gateway-admin` / `gateway-test` and tests, ADR-0010, new glossary terms, and the step write-up.
- Step 11: Postgres + pgvector document and vector store: the digest-pinned, tuned, localhost-only `rag-db` (pgvector 0.8.7 on Postgres 17, `pg_stat_statements`) in Compose with four role-password secrets, the one-time init script `infra/config/rag-db/init/01-roles.sh` (extensions, `rag` schema, `rag_migrator` / `rag_app` / `rag_readonly` with default privileges and timeouts), dbmate in the Brewfile with `just db-migrate` / `db-psql`, the first migration (`collections`, `documents`, `chunks` with `halfvec(1024)` HNSW and full-text GIN indexes), `scripts/pg_demo.py` permission-aware semantic search, `just db-backup` / `db-restore-test` with `backups/` gitignored, role passwords in the secrets generator and `.env.example`, tests, ADR-0011, new glossary terms, and the step write-up.
- Step 12: Qdrant as a derived vector index: the `qdrant` service (v1.19.2 pinned by tag@digest, admin and read-only keys from secret files, telemetry off, JWT RBAC on, 6333/6334 on 127.0.0.1 only, 6335 unpublished, data and snapshot volumes), both keys in the secrets generator and `.env.example`, `just qdrant-health` / `qdrant-snapshot`, `scripts/qdrant_setup.py` (versioned `rag_chunks_qwen3e06b_v1` with float16 dense + sparse slot, HNSW, int8 quantization, payload and tenant indexes, alias `rag_chunks`), `scripts/qdrant_sync.py` (read-only mirror from Postgres plus permission-filtered search with rescoring), `scripts/qdrant_token.py` (read-only, collection-scoped, expiring JWT), `qdrant-client` and `pyjwt` dev dependencies, tests, ADR-0012, new glossary terms, and the step write-up.
- Step 13: OpenSearch for keyword and hybrid search as a derived index: the `opensearch` service (3.8.0 pinned by tag@digest, admin password from a secret file via a wrapper, single node, locked 2 GB heap in a 4 GB limit, TLS and security plugin, 127.0.0.1:9200 only, password-free healthcheck, data volume), three strong passwords in the secrets generator and `.env.example`, `just os-health` / `os-count`, `scripts/os_setup.py` (`rag_search` / `rag_indexer` least-privilege users, `rag-chunks-v1` with stemming, query-time `synonym_graph` synonyms, keyword ACL fields and a Lucene HNSW 1024-d vector behind alias `rag-chunks`, and the `rag-hybrid` min-max / 0.3-0.7 pipeline), `scripts/os_demo.py` (Postgres-first ingest, sync, BM25 vs vector vs hybrid with permission filters, explain), the `opensearch-py` dev dependency, tests, ADR-0013, new glossary terms, and the step write-up.
- Step 14: S3 object storage for original files with SeaweedFS: the `object-store` service (SeaweedFS 4.45 `weed mini` pinned by tag@digest, admin / rag-ingest / rag-reader identities built from six secret files into a RAM-only tmpfs with bucket-scoped actions, telemetry off, only 127.0.0.1:8333 published), the six `S3_*` keys replacing the Step 6 `MINIO_*` secrets in the generator and `.env.example`, `awscli` in the Brewfile and `just s3`, `scripts/s3_setup.py` (`rag-raw-docs` versioned with 90-day non-current expiry, `rag-audit-archive` with governance object lock, `rag-tmp` with 1-day expiry), `scripts/s3_demo.py` (versions, least privilege, version-pinned presigned links, object lock, lineage on the Postgres document row), `boto3` / `boto3-stubs[s3]` dev dependencies, tests, `docs/data/object-storage.md`, ADR-0014, new glossary terms, and the step write-up.
