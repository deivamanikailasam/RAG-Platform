# Coverage audit: the build guide against this repository

After all 38 steps were built, the guide's three appendices and its introduction were checked against the
repository. The aim was to confirm that every file, command, term, component and folder the guide names
really exists here, and to fix whatever didn't. This page records what was checked, how, and the result.

Audit date: 2026-10-13 · Guide edition v0.38 (38 of 38 steps).

## How it was checked

| Check | Method |
|---|---|
| Appendix A files | Every path in Appendix A's tables tested for existence (`test -e`), with the guide's `~/dev/rag-platform/` read as the repository root and home-folder files looked up under `bootstrap/home/`. |
| Appendix A commands | `just --summary` compared both ways with every `just <recipe>` in Appendix A. |
| Appendix B glossary | The appendix parsed into 672 entries (term, meaning, step) and matched against `docs/glossary.md` by name and by each part of a compound name ("A / B", "A (B)"); the leftovers reviewed by hand. |
| Appendix C catalogue | `docs/catalogue.md` compared with Appendix C: kinds, component names, the "Tested" status counts, and `just catalogue --check`. |
| Introduction | Every component in "The full scope of Project 0" and every folder in the folder map looked up in the repository. |

## Not committed by design

These appear in Appendix A or the folder map but are created on your own machine. Committing them would
mean committing a private key or a real secret.

| Guide item | What the repository has instead |
|---|---|
| `secrets/dev.enc.env` | Created by `just secrets-init` (`scripts/new-dev-secrets.sh`) with your age key; every name it holds is in [`.env.example`](../.env.example); instructions in [`secrets/README.md`](../secrets/README.md) |
| `secrets/openbao-init.enc.json` | Created by `just vault-init`, which pipes the unseal keys straight into SOPS |
| `~/.config/sops/age/keys.txt` | Your age private key: never committed; steps in `secrets/README.md` |
| `~/.ssh/id_ed25519` (+ `.pub`), `~/.ssh/allowed_signers` | Made by [`bootstrap/git-setup.sh`](../bootstrap/git-setup.sh); `bootstrap/home/.ssh/allowed_signers.example` shows the format |
| `~/Library/Logs/rag-platform/*.log`, `~/.cache/huggingface/hub/` | Runtime output on the Mac |
| `backups/`, `evals/runs/`, `.bao/`, `.tools/bin` | Git-ignored working folders (listed in [`.gitignore`](../.gitignore)) |
| `evals/baselines/*.json` | The folder exists (with `.gitkeep`); a baseline is the summary of a real accepted run, written by `just evals baseline <run>` against the live models, so none can be produced honestly in this container |
| `~/dev/sandbox/` | Outside the repository by design; the labs that use it are [`bootstrap/labs/`](../bootstrap/labs/) |
