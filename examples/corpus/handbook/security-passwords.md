# Passwords and multi-factor authentication

## Passwords

Passwords must be at least 14 characters long. Use a passphrase of several random words, and keep
every password in the company password manager. Never reuse a work password anywhere else.

## Multi-factor authentication (MFA)

MFA is required for every company system. Use the Okta Verify app or a hardware security key.
SMS codes are not allowed as a second factor, because phone numbers can be hijacked.

## If a password leaks

Change it at once and tell the security team through the Report a security incident form.
